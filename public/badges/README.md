# Badge artwork

Drop your badge images here using these exact filenames. Until a file
exists, the app shows the badge's emoji instead (graceful fallback —
nothing breaks).

| Badge              | Filename                  |
|---------------------|---------------------------|
| First Step          | `first-step.png`          |
| Streak Starter      | `streak-starter.png`      |
| Week Warrior        | `week-warrior.png`        |
| Ten-Day Champion    | `ten-day-champion.png`    |
| Eco Vanguard        | `eco-vanguard.png`        |
| Eco Legend          | `eco-legend.png`          |
| Monthly Guardian *  | `monthly-guardian.png`    |

\* One shared image is used for every month (September Guardian,
October Guardian, etc.) — only the badge name/description changes
per month, not the artwork.

Recommended: square PNG, transparent background, at least 320x320px
(they're drawn onto a 1080x1080 share card at that size).
